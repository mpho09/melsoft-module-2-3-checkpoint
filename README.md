## what the project is about
It has covered module 2 and 3. Module 2 taught you how to name and store data: variables, data types, type
casting and comments. Module 3 taught you how to work with that data: arithmetic,
assignment, comparison, logical, bitwise, unary, ternary and the special operators (typeof,
instanceof, delete), plus user interaction through alert, confirm and prompt.
